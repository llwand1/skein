# Skein · 桌面端 MVP（M0 + M1）

一颗常驻角落的球 + 一套不预设数量的叙事骨架。

## 怎么跑

- 双击 `run.bat`（带控制台，第一次跑看报错用）
- 或双击 `run-silent.vbs`（无控制台，日常用）

依赖：Python 3.11+ ＋ **PyQt6** ＋ pywin32（sqlite 内置）。已在本机验证齐备。

> UI 层用 **PyQt6** 渲染：逐像素 Alpha + 真抗锯齿 + 柔和投影。早期 Tk 版因为
> Canvas 无抗锯齿、透明靠颜色键，边缘必然硬齿，已废弃。

## 怎么用

面板是**平的**——没有"第几步"，这些入口一直在同一屏，想用哪个用哪个。
**整块面板都能拖**（不只标题栏）；点一下不会乱跳（刷新会待在原来的滚动位置）。

1. **球是空的**（虚线圆 + "+"）——此时还没有在做的这一期
2. 点球展开面板 → 在「喂」那一格里写下你看到的东西，目标留 **灵感池（不挂靠）** → 点「喂进去」
   - **灵感池是一口池子**（液态玻璃，和球同一套材质）：喂进去的东西会从池口**落下来泡在里面**，金色那条线是水位。类型靠**形状**读（细横条=文字、方块=图片、宽条=视频、窄条=音频），**点一下池子**才摊开列表。
3. 想清楚了 → 同一屏里给这一期**起个名**（比如「MCP 到底创新在哪」）→ 点「立项」→ AI 给出**初始理解**（3 段骨架），灵感池里那几条一并带进来
   - 名字打错了随时改：主题头上的 **「改期名」**；**payoff 卡上的「改」** 同一个人可以改。这两处只动字段，结构和素材不受影响，不用重开一期。
4. 继续喂：目标下拉换成某一节拍 → 「喂进去」（每喂一条，AI 重算「下一步」，结构可能自己长出新段）。下拉的 index 0 恒为「灵感池」（＝不挂靠）
5. **收真素材**：点「＋ 文件」选文件，或**直接把文件拖到面板上** —— 图片 / 视频 / 录音 / 长文都行。文件会**复制**进 `%LOCALAPPDATA%\Skein\assets\`（原件不动），图片还有缩略图。落在哪一段同样看目标下拉。
6. **聊思路**：在「聊」那一格里说人话（"我想从『成本』这个角度切"、"第 2 段太学术了"），它接话；要动结构或改稿会先列出来，你点 **「照做」** 才动
7. 某段有素材后，那一行的行内就长出「够了，这段讲清了」——**想确认哪段点哪段**，不必按顺序
8. **结构你自己也能改**：每段右侧一排小按钮 —— **＋** 在这段后面插一段（插完立刻让你写它）；**↑ ↓** 上下挪；**改** 就地改措辞（回车提交、Esc 退出）；**×** 撤下（段里的素材退回「未指派」，一条不丢）。或者**按住这一行上下拖**直接换位
9. **点标题就能深入这一点**（标题前的 `▸/▾` 就是提示）——展开后有两件事可做：
   - **详细论证这一点**：AI 用**这一段的素材**把主张和支撑补起来，并指出**还缺什么**（存进这一段）
   - **就这一点发散**：给几个能长成新段的方向（每条带依据），点「升成一段」就真的长出一段
   - 两条都只用这一段的素材；撑不住的地方它会直说缺，不会编。没模型时走本地规则，界面会明说。
10. 任何时候都能点触发条右端那个 **小勾 ✓** 收口（有主题、至少一段即可）—— 悬停写着「够了，收口 —— 上限由你定」
11. **交付物：成片稿 · 分镜表** —— 每段一行：`要回答什么｜口播稿｜要什么画面｜手上素材`。
    可「复制分镜表」、「导出 Markdown…」、「打开素材文件夹」，也能「重写成片稿」让模型按现在的素材再写一版。
12. **导出编排包（M4，已做）**：点 **「导出编排包」** —— 把这一期编译成一份施工单
    （分镜表 / **生成画面的提示词** / 镜头级时间轴 / 字幕 / 口播稿 / 素材清单 / 剪映草稿），
    交给剪映 / 即梦 / 可灵去出片。命令行：`python export_pack.py --topic <id> --target 剪映`。
    铁律：**同一个画面在这支片里只排一次**；缺的画面不空着，给提示词让 AI 去生成 ——
    **画面是什么由 Skein 定，别临场改，改了就跑出编排之外。**

**注意：完成度永远只到 92%，最后一格由你点。** 这是设计，不是 bug。
面板里**没有任何预置内容**——没有排期表、没有示例期名、没有预填素材。空白就是空白。
对话**只活在这次运行里**（不进库）；模型不通时它会直说，不会假装能聊。
**没模型也能走到头**：分镜表会用本地规则那版（口播稿＝把这一段已有素材串起来，画面＝有图就说用它、没有就写"待定"）。

## 操作

| 动作 | 方式 |
|---|---|
| 打开/收起面板 | 点球 / 右键球 / **Ctrl+Alt+S** |
| 拖动球 | 按住球拖 |
| 球右键菜单 | 面板、不抢焦点自检、退出 |
| 面板内提交 | **Ctrl+Enter** |

## M0 验收（必须先过）

1. 打开浏览器，点进一个输入框，开始打字
2. 让球显示 / 点一下球
3. **看浏览器里的光标和选区还在不在**

- 还在 → **M0 通过**
- 丢了 → **M0 不通过**，需要换实现方式（不要硬扛）

球右键 → 「不抢焦点自检」会把前后两次的前台窗口与光标控件写进日志。

## 文件

```
app/
  main.py      入口：单实例、热键、状态聚合
  orb.py       悬浮球（置顶 / 不激活 / 三态）
  pool.py      灵感池（液态玻璃池子：水位 + 泡着的素材 + 落下动效）
  panel.py     面板（灵感池 / 立项 / 喂 / 确认 / 估算 / 封顶 / 分镜表 / 编排包）
  store.py     SQLite 数据层
  brain.py     本地规则大脑（下一步 / 估算 / 结构生长 / 成片稿）
  arrange.py   编排引擎（M4）：镜头规划（同画面只排一次）/ 时长 / 提示词 / 时间轴 / SRT
  export_pack.py 编排包导出：施工单 + 剪映草稿（命令行与 GUI 共用）
  winutil.py   Win32：不抢焦点、前台/光标探针
  config.py    路径与常量
run.bat / run-silent.vbs
```

## 编排包（M4）—— 项目不出片，只编排

**Skein 不渲染视频。** 它的活到"编排"为止：每段讲什么、画面是什么、顺序、时长、
缺的画面要生成什么样 —— 编完导成施工单，由剪映 / 即梦 / 可灵 / Runway 去出片。
这样出片效果才跑不出编排的框：画面内容在这里就定死了，别的软件照做。

- 引擎：`arrange.py`（不依赖 ffmpeg，不做渲染，不配音）
- 产物：`%LOCALAPPDATA%\Skein\packs\topic-<id>\`
  - `读我.md` — 这个包怎么用（先生成画面 → 按时间轴摆 → 配音）
  - `分镜表.md` — 人读施工单：段 / 口播稿 / 镜头 / 画面来源 / 运镜 / 字幕
  - `提示词.md` — **待生成镜头**的提示词，丢给即梦 / 可灵 / MJ / Runway
  - `时间轴.json` — 机读：镜头级入点、时长、素材绝对路径、运镜、字幕
  - `字幕.srt` / `口播稿.txt` / `素材清单.md`
  - `剪映草稿/` — pyJianYingDraft 生成的草稿，拷进剪映草稿目录即可导入
- 红线：同一个素材只排进一个镜头（内容指纹去重，跨段也算）；
  素材不够 → 标「待生成」并给提示词，绝不把同一个画面排第二遍。
- 可选依赖：`pyJianYingDraft`（只在要剪映草稿时才用，缺了其它文件照出）。
- 占位图防线：小于 360px 边长的图一律当占位图拦掉（1×1 的 PNG 是坑，踩过）。
